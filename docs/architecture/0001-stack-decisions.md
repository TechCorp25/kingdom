# 0001 — Kingdom stack decisions

- Status: accepted
- Date: 2026-05-23

## Context

Kingdom is a local-first control plane whose API is consumed primarily by Claude
Code through an MCP server, plus internal tooling — not by browser sessions. The
initial scaffold used Flask + pip + requirements.txt, which prompted a review
before the first real build session.

## Decisions

### Package management: uv

uv (Astral) is the de facto standard for modern Python as of 2025: a single fast
tool for environments, dependency resolution, locking (`uv.lock`), and running.
Replaces the pip + manual venv + requirements.txt workflow. Dependencies live in
`pyproject.toml`; dev tooling in a `[dependency-groups] dev` group.

### API framework: FastAPI (not Flask)

Kingdom's API is a stateless internal service. FastAPI fits better than Flask
because it is async-native (matching async SQLAlchemy and the MCP server), is typed
end to end via Pydantic, and auto-generates OpenAPI docs at `/docs`. It also removes
the need for Flask's session machinery — and therefore the `FLASK_SECRET_KEY` that
triggered this review, which was a symptom of using a session-oriented framework for
a sessionless API. Flask remains the right tool for the separate Le Répertoire
project; it is not the right tool here.

### Data layer: PostgreSQL + SQLAlchemy 2.0 async + Alembic

PostgreSQL for the control plane (per the original design). SQLAlchemy 2.0 with the
async `asyncpg` driver and typed `Mapped[...]` models. Alembic with an async-aware
`env.py` for migrations. A deterministic constraint naming convention keeps
autogenerated migrations stable.

### MCP server: official `mcp` SDK FastMCP

The official Model Context Protocol Python SDK ships FastMCP
(`from mcp.server.fastmcp import FastMCP`) with decorator-registered tools. Used
over stdio transport, which is what Claude Code launches. Chosen over the separate
third-party FastMCP 2.0 package to stay on the first-party, documented surface.

### Shared service layer

Business logic lives in `services.py`, consumed by both the FastAPI routes and the
MCP tools. This guarantees the two surfaces never diverge in behaviour.

### Package layout: src/kingdom

A `src/` layout with a single installable `kingdom` package. This also resolves the
earlier `platform/` directory name, which shadowed Python's stdlib `platform`
module.

## Consequences

- One toolchain (`uv run ...`) for every task; reproducible via `uv.lock`.
- `.mcp.json` points at the `kingdom-mcp` console script installed into `.venv`.
- The first migration and a Project/Task/Memory vertical slice ship working, with
  passing tests, clean ruff, and strict mypy, establishing the pattern for the
  remaining entities.
