# Policy — Python / FastAPI gotchas (hard-won)

## `from __future__ import annotations` + FastAPI = HTTP 422
Do **NOT** add `from __future__ import annotations` to any module used as a FastAPI
class-instance `Depends()`, or to route files. It turns annotations into strings, so
FastAPI mis-reads a request/dependency param as a query field and the endpoint returns
HTTP 422 on every call.
- Concretely bit `backend/security/rate_limit.py` (rate-limited routes all 422'd) and
  recurs in route files. When in doubt, leave it out of route/Depends modules.
- It is fine (and used) in plain library/service/script modules — e.g. Kingdom's
  `services.py`, `entities.py`, and `scripts/`.

## Test-harness notes (IlluminateMyGallery backend)
- `mongomock_motor` backs the lazy `db._db`; `litellm` is stubbed via `sys.modules`.
- Reset the rate limiter between tests via `get_limiter().reset()` in the `fresh_state`
  autouse fixture. See `backend/tests/conftest.py`.
- Mock boto3 at the adapter boundary (`unittest.mock.patch`) — don't hit real R2.

## Kingdom platform
- Async DB access only, via `session_scope()` (commit/rollback/close handled).
- `uv run mypy` is **strict** and must stay green; type everything.
- Migrations: review autogenerated output before apply; constraint names follow
  `models/base.py` so diffs stay deterministic.
- Business logic lives in `services.py`, shared by API and MCP — keep both surfaces thin
  so they never diverge.
